# 版本存档

这里按交付顺序原样保存每一版设计包（zip 解压后的内容），方便回溯「某一版长什么样」、对比改动。

**注意**：文件夹里是**收到的原始设计包**，不含 CMS 适配。线上部署的版本在此基础上还多了：

- `index.html` 里的 `data-cms` 标记
- `content/site.json`、`admin/`、`src/worker.js`
- 改写过的 `_headers`（缓存策略）和 `robots.txt`

要看某一版实际部署了什么，用 git 查对应提交即可。

| 版本 | 交付日期 | 部署提交 | 主要变化 |
|---|---|---|---|
| `0.2` | 2026-11-18 | `060fd20` | 初版三屏：手机壳 / 手机膜 / 联系方式（聊天卡片 + 二维码） |
| `0.2.1` | 2026-11-20 | `8135083` | 顶栏去掉右上角 Learn More 按钮；第 3 屏改版：去掉聊天气泡，改成左边二维码、右边小标题 + 大号电话 + 营业时间 + Call Now |

## 怎么回滚到某一版

```bash
git log --oneline                       # 找到那一版的提交
git show <提交>:index.html > index.html # 单独看某个文件
```

完全回滚整站：`git revert <提交>` 或直接把对应提交里的文件覆盖过来。改完推上去，Cloudflare 会自动重新部署。

`versions/` 不在部署范围内（见 `.assetsignore`），只作为仓库留档。
